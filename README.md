# Ashiq-DataArt
A simple responsive timeline of AI milestones with dark mode.
## Features
- Shows key AI events from 1950 to 2025
- Dark/light mode toggle
- Works on phones, tablets, and computers
- Clean, easy-to-read design
## What's Inside
- Single HTML file with built-in CSS and JavaScript
- No extra files or setup needed
